Penjelasan Apa itu Version Control

perangkat lunak yang digunakan untuk melacak, mengelola, dan menyimpan perubahan pada source code proyek dari waktu ke waktu

Perbedaan Git dan Github

Git adalah sistem kontrol versi lokal (software) yang terinstal di komputer untuk melacak perubahan kode, sedangkan GitHub adalah platform berbasis cloud (web) untuk menyimpan, berbagi, dan berkolaborasi secara online

Penjelasan Apa itu HMTL

HyperText Markup Language adalah standard markup language yang digunakan untuk membuat dan menyusun halaman web. Halaman web disusun dari beberapa tulisan yang berisi heading, paragraf, link, gambar dan atribut lain di dalam dokumen HTML.
